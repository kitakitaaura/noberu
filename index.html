about

The first web-based visual novel porter, filled with multiple emulators and ports.

01
Local-first ports Games run inside your browser. Your files stay on your device. While the whole ports are fully static, through WASM and emscripten, local games can be efficiently and reliably ported to the web.
02
Supported runtimes Ren'Py, NScripter, RealLive, KiriKiri, Siglus, TyranoBuilder, RPG Maker MV/MZ, VNDS and PS2, with more on the way. Each tab is a real engine or emulator built for the browser: Ren'Py (8, 7 and 6.99), ONScripter, onscripter-ru and Ponscripter for NScripter-style games, rlvm for RealLive, Kirikiroid2 for KiriKiri, siglus_rs for SiglusEngine, TyranoScript and RPG Maker MV/MZ served as-is, VNDS-LÖVE, Play! for PS2, and an early BoxedWine for Windows builds.

BoxedWine runtime

boxedwine

Runs a zipped Windows build based on a WASM runtime of Wine.

Boxedwine as of right now has no OpenGL support, eliminating almost the majority of visual novels after 2010. Also, super ambitious and huge visual novels like Clannad almost never load, and get stuck during loading. This is a proof-of-concept, not a production-ready runtime, and this is the build that's buing improved on the most as well as being the one you should try as a last resort.

vnds

Plays VNDS-format novels through an WASM port of VNDS-LÖVE. Upload a novel folder, or continue a previously installed one.

This does NOT play the original visual novel. It is rather a simple lightweight "format" of some sort that easily and quickly runs the basic mechanics of a visual novel. It is not a true replacement or even an adaquate one for multiple visual novels.

ren'py runtime

ren'py

Plays Ren'Py games through Ren'Py's own Emscripten build — the engine ships this target itself, so nothing here was ported.

Ren'Py 8, 7 and 6.99 games (DDLC) all work. 8 and 7 split at Python 3 versus Python 2 and cannot read each other's bytecode, so there is a runtime for each; the tab reads the game's version and picks.

No folder selected Choose the game folder (the one with the .exe and a game/ subfolder), or the game/ folder itself.

Render scale (lower it if the game stutters)Render scale — the engine has no threads here, so a 1080p game draws every frame on one thread. Drop this if it stutters; the picture is scaled back up to fill the frame either way.

Unlike the other tabs, Ren'Py's web build unpacks the whole game into memory before it starts, so staging takes a moment and games past about 1.2 GB may run out of it. Saves persist in this browser's private storage (IndexedDB), per game.

Right click opens the game menu. Hold Ctrl to skip.

noberu v0.4 — beta

This is a BETA release. Things break, games fail to boot, and saves can be lost between updates.

Every tab runs a real engine or emulator in your browser, which asks a lot of a machine. On weaker systems expect long loads, stutter, or games that never start at all.

New in v0.4: your games on one shelf, a menu in every game (press `tap menu), and reading tools with a Japanese dictionary.

Questions, bugs, or a game that will not run — dm farisnyanyann on Discord.
