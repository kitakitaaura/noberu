BoxedWine runtime

boxedwine

Runs a zipped Windows build based on a WASM runtime of Wine.

Boxedwine as of right now has no OpenGL support, eliminating almost the majority of visual novels after 2010. Also, super ambitious and huge visual novels like Clannad almost never load, and get stuck during loading. This is a proof-of-concept, not a production-ready runtime, and this is the build that's buing improved on the most as well as being the one you should try as a last resort.

VNDS-LOVE runtime

vnds

Plays VNDS-format novels through an WASM port of VNDS-LÖVE. Upload a novel folder, or continue a previously installed one.

This does NOT play the original visual novel. It is rather a simple lightweight "format" of some sort that easily and quickly runs the basic mechanics of a visual novel. It is not a true replacement or even an adaquate one for multiple visual novels.

No folder selected Choose a VNDS novel folder (it has an info.txt and script/background/sound assets or zips inside).

Novels persist to this browser's IndexedDB once installed - "continue" boots straight in without re-uploading anything.

rlvm runtime

rlvm

Plays RealLive-era Key games through a WASM port of rlvm. Upload the game folder and it runs, art, voices and all.

This runs the real game, not a reimplementation: Kanon, Air, Clannad, Little Busters and Planetarian all use RealLive. The whole folder is loaded into memory before the game starts, so a large game takes a moment to stage and then plays without streaming hitches.

No folder selected Choose the folder holding Gameexe.ini and Seen.txt (or its KINETICDATA/REALLIVEDATA subfolder).

Saves persist to this browser's IndexedDB, so in-game saves survive a reload. The game folder itself is staged fresh each session and never leaves this device.

onscripter runtime

onscripter

Plays NScripter games through a WASM build of ONScripter (the OnscripterYuri fork).

Covers the big NScripter library: Tsukihime, the original Higurashi and Umineko releases, Narcissu, and most doujin visual novels shipped with nscript.dat or 0.txt plus .nsa/.sar archives. Files are read from this device only when the game first opens them, so staging is instant.

No folder selected Choose the folder holding nscript.dat, 0.txt or 00.txt.

Saves persist to this browser's IndexedDB, per game folder name. Esc or a right click opens the game's own menu; hold Ctrl to skip.

onscripter-ru runtime

onscripter-ru

Plays the Umineko Project release through a WASM build of onscripter-ru, the Umineko Project's own ONScripter fork.

Nothing is copied: the game reads each file straight from this device when it needs it, so even the full 12 GB release stages in seconds. The engine runs on worker threads and draws through WebGL, so it needs a recent Chrome or Edge.

No folder selected Choose the Umineko folder (the one holding default.cfg, en.file and game.hash).

Saves and settings persist in this browser's private storage (OPFS), per game folder name. Right click opens the game menu. The first launch checks every file once, then right click to continue.

ren'py runtime

ren'py

Plays Ren'Py games through Ren'Py's own Emscripten build — the engine ships this target itself, so nothing here was ported.

Ren'Py 8 and Ren'Py 7 games both work. The two split at Python 3 versus Python 2 and cannot read each other's bytecode, so there is a runtime for each; the tab reads the game's version and picks.

No folder selected Choose the game folder (the one with the .exe and a game/ subfolder), or the game/ folder itself.

Render scale — the engine has no threads here, so a 1080p game draws every frame on one thread. Drop this if it stutters; the picture is scaled back up to fill the frame either way.

Unlike the other tabs, Ren'Py's web build unpacks the whole game into memory before it starts, so staging takes a moment and games past about 1.2 GB may run out of it. Saves persist in this browser's private storage (IndexedDB), per game.

tyrano runtime

tyrano

Plays TyranoScript and TyranoBuilder games: the engine is HTML and JavaScript already, so this tab serves the folder rather than emulating anything.

A service worker answers the game's own asset requests out of the folder you picked, reading each file only when the game opens it. Nothing is copied and nothing is uploaded.

No folder selected Choose the folder holding the game's index.html (with tyrano/ and data/ beside it).

Saves are the game's own, kept in this browser's storage for this site. A game that shipped as a Windows .exe usually has the same folder inside it — stage that one.
